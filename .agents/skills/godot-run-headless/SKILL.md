# godot-run-headless

Path for Godot executable to run the game in headless mode.

## Usage

Use when running tests for nodes.

## Steps

1. Run Godot in Pistoleros-Of-Santa-Rose directory with the following command:

```bash
cd c:/Users/h3tul/Documents/Pistoleros-Of-Santa-Rose && "/c/Program Files (x86)/Steam/steamapps/common/Godot Engine/godot.windows.opt.tools.64.exe" --path . --headless --script {{script_path}}
```
